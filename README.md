## 來源與建置

原始研究資料與建置腳本位於本資料夾：
- `build.mjs`：彙整候選、合併批次、產生 `data.json` / CSV / 統計

- `dist/package-manifest.json`：單檔大小、雜湊與各模組資訊

更完整說明請見原專案 `R2詳細說明.md` 與 `手動驗收表.md`。
